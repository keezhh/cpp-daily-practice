# Day 1 – Introduction to Loops

## Topics Covered
- For Loop
- While Loop
- Do-While Loop
- Increment and Decrement Operators

## What I Learned
I learned about the three types of loops in C++: `for`, `while`, and `do-while`.

- **For Loop** – Used when I already know how many times I want a block of code to run.
- **While Loop** – Repeats a block of code as long as the given condition is true.
- **Do-While Loop** – Runs the code inside the `do` block first, then checks the condition in the `while` statement. This means the code always runs at least once.

I also learned about the increment (`++`) and decrement (`--`) operators, which increase or decrease a variable's value by 1.
